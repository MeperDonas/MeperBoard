# MeperBoard

A local-first kanban/backlog board for the Meper suite's GitHub issues.

MeperBoard gives a single, offline-first pane over the issue backlog of connected repositories (starting with [MeperPOS](https://github.com/MeperDonas/MeperPOS)), with local cards, slice/feature grouping, and read-only GitHub sync.

## Status

Early development — MVP in progress.
